# Public showcase checklist

Before pushing this repository public:

- [ ] Confirm no private URLs or credentials are present.
- [ ] Replace the example Kubernetes image registry with the real public image after publishing.
- [ ] Add screenshots of `/docs` and Grafana after a local run.
- [ ] Record one CI run and one evaluation run in the README.
- [ ] Add an architecture image if desired.
- [ ] Add a release tag after the first verified public run.
- [ ] Replace the example GitHub URL in the Medium draft with the final repository URL if the repository name changes.
